# 🤖 Claude Code Limits Checker (Multi-Account & Coolify Support)

Простой и надежный сервис на Python для автопроверки состояния лимитов **одного или нескольких аккаунтов Claude Code** и получения уведомлений в **Telegram**.

Полностью адаптирован для **развертывания в Coolify** (или на любом Linux VPS в Docker) без зависимости от вашего компьютера!

---

## ✨ Возможности

- 🚀 **Полная поддержка Coolify**:
  - Быстрое развертывание через Dockerfile / Git репозиторий в Coolify.
  - Поддержка конфигурации через переменные окружения (`CONFIG_JSON` или `BOT_TOKEN` + `CHAT_ID`).
  - `PYTHONUNBUFFERED=1` для мгновенного просмотра логов в веб-интерфейсе Coolify.
  - Встроенный Healthcheck.
- 👥 **Поддержка нескольких аккаунтов**:
  - Автоматический сбор всех аккаунтов из **macOS Keychain** при экспорте.
  - Возможность добавления любых дополнительных аккаунтов.
- 🔄 **Автоматическая ротация токенов (OAuth Auto-Refresh)**:
  - Внутри контейнера Coolify сервис самостоятельно обновляет истекающие OAuth-токены прямо через API Anthropic без использования браузера или Claude CLI.
- 📊 **Просмотр статуса**:
  - 5-часовой лимит, 7-дневный лимит и баланс Extra Usage для каждого аккаунта с точным обратным отсчетом до сброса.
- 💬 **Telegram-бот**:
  - Команды `/status` и `/check` в Telegram выводят наглядный отчет по всем аккаунтам.
- 🔔 **Персональные уведомления**:
  - Уведомляет, когда 5-часовой лимит достиг 100% (с указанием времени до сброса).
  - Уведомляет, когда лимит аккаунта **сбросился** и можно продолжать работу!
- ⚡️ **Zero Dependencies**: работает на стандартной библиотеке Python 3.9+ без `pip install`.

## 🔑 Как авторизовать несколько аккаунтов через сайт Claude.ai

Есть два простых способа привязать второй (и последующие) аккаунты:

### Способ 1. Через `claude auth login` на Mac (30 секунд)

1. Откройте ваш браузер и войдите под нужным аккаунтом на сайте [claude.ai](https://claude.ai).
2. В терминале на Mac выполните:
   ```bash
   claude auth login
   ```
3. Нажмите кнопку **Authorize** в браузере. Токен сохранится на компьютере.
4. Чтобы добавить еще один аккаунт — смените аккаунт на [claude.ai](https://claude.ai) (или откройте вкладку инкогнито) и снова выполните `claude auth login`.
5. Выполните экспорт для получения общего конфига с обоими аккаунтами:
   ```bash
   python3 claude_checker.py export
   ```

---

### Способ 2. Ввод токенов вручную

Если у вас есть Access Token и Refresh Token второго аккаунта:
```bash
python3 claude_checker.py accounts
```
Выберите пункт `2. Добавить новый аккаунт по OAuth Токену` и введите:
- Название аккаунта (например: *Второй аккаунт*)
- **Access Token** (`sk-ant-oat01-...`)
- **Refresh Token** (`sk-ant-ort01-...`)

## 🛠️ Развертывание в Coolify (Занимает 2 минуты)

### Шаг 1. Экспортируйте конфиг с токенами на локальном Mac
В терминале на вашем Mac выполните:
```bash
python3 claude_checker.py export
```
Скрипт выведет готовое значение для переменной окружения `CONFIG_JSON` (содержащее ваши токены и настройки бота).

---

### Шаг 2. Создание приложения в Coolify

1. Перейдите в **Coolify** → **Applications** → **+ Add Resource** → **Public/Private Repository** (или Dockerfile).
2. Укажите этот репозиторий / папку.
3. Выберите тип сборки: **Dockerfile** (или Docker Compose).
4. Перейдите во вкладку **Environment Variables** в Coolify и добавьте 1 переменную:
   - **Key**: `CONFIG_JSON`
   - **Value**: Вставьте строку, полученную на Шаге 1 из `python3 claude_checker.py export`.

5. Добавьте вторую переменную и **persistent storage**:
   - **Key**: `STATE_FILE`, **Value**: `/data/state.json`
   - В **Storages** примонтируйте volume на `/data`.

6. Нажмите **Deploy**!

Сервис автоматически запустится, отправит вам приветственное сообщение в Telegram и будет работать круглосуточно 24/7!

> ⚠️ **`STATE_FILE` на persistent volume обязателен.** Anthropic ротирует refresh-токен
> при каждом обновлении. Новый токен пишется в `state.json`; `CONFIG_JSON` из ENV остаётся
> со старым и перекрывает файл при старте. Без персистентного `state.json` после первого же
> перезапуска контейнера аккаунт получит `invalid_grant` и перестанет отвечать навсегда —
> вернуть его можно будет только новым `export`.

## 🔐 Ограничение доступа к боту

Бот отвечает только чатам из белого списка: `chat_id` из конфига плюс `allowed_chat_ids`
(в конфиге списком или в ENV `ALLOWED_CHAT_IDS` через запятую). Сообщения от остальных
игнорируются и логируются — иначе состояние ваших лимитов увидит любой, кто найдёт бота.

## 👥 Про несколько аккаунтов на macOS

Claude Code CLI хранит учётные данные в Keychain под `acct` = имя пользователя macOS.
Записи разделяются только по имени сервиса, а перелогин перезаписывает текущую запись —
поэтому **переключение аккаунтов в CLI не создаёт вторую запись**. Десктопное приложение
(в т.ч. отдельная копия) хранит sessionKey в куках Electron, а не OAuth-токен, и для
`oauth/usage` не подходит.

Рабочая схема для второго аккаунта: залогиниться в него, сразу выполнить `export`,
и добавить пару токенов как аккаунт `type: "token"`. Дальше скрипт обновляет его
самостоятельно и хранит ротации в `state.json`, независимо от того, под кем вы вошли в CLI.

## ⚙️ Полезные команды CLI

| Команда | Описание |
| :--- | :--- |
| `python3 claude_checker.py status` | Показать текущий статус всех аккаунтов в консоли |
| `python3 claude_checker.py export` | Сформировать переменную `CONFIG_JSON` для вставки в Coolify |
| `python3 claude_checker.py setup` | Интерактивный мастер настройки Telegram бота |
| `python3 claude_checker.py accounts` | Управление списком аккаунтов |
| `python3 claude_checker.py daemon` | Запустить фоновый процесс локально |
