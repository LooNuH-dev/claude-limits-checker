# 🤖 Claude Limits Checker

Мультипользовательский Telegram-бот для отслеживания лимитов **Claude Code** (5-часовой и
7-дневный лимиты, баланс Extra Usage) с уведомлениями в реальном времени. Каждый
пользователь подключает свои аккаунты Claude через OAuth прямо в чате с ботом, доступ к
боту выдаётся по инвайтам.

Полностью адаптирован для **развёртывания в Coolify** (или на любом Linux VPS в Docker).

---

## ✨ Возможности

- 👥 **Мультипользовательский режим**: каждый пользователь видит и управляет только
  своими аккаунтами Claude.
- 🎟 **Доступ по инвайтам**: администратор выдаёт одноразовые ссылки-приглашения,
  посторонние пользователи ботом воспользоваться не могут.
- 🔐 **Вход через OAuth прямо в Telegram**: без Keychain, без CLI и без экспорта
  конфигов — кнопка «Войти в Claude» → код из браузера → сообщение с кодом.
- 🖱 **Инлайн-меню**: список аккаунтов, статус лимитов, добавление/удаление аккаунтов
  и админ-панель — всё через кнопки.
- 🔄 **Авто-обновление OAuth-токенов**: токены обновляются в фоне без участия
  пользователя.
- 🔔 **Фоновый монитор**: уведомляет владельца аккаунта, когда лимит достиг 100%
  и когда лимит сбросился.
- 🩺 **Админка**: список пользователей, отзыв доступа, диагностика последних ошибок.
- 🔒 **Шифрование токенов в БД**: все OAuth-токены хранятся в SQLite зашифрованными
  (Fernet, `ENCRYPTION_KEY`).

## ⚙️ Переменные окружения

| Переменная          | Обязательна | По умолчанию   | Описание                                                   |
| ------------------- | :---------: | -------------- | ----------------------------------------------------------- |
| `BOT_TOKEN`         |     ✅      | —               | Токен Telegram-бота от [@BotFather](https://t.me/BotFather). |
| `ADMIN_TELEGRAM_ID` |     ✅      | —               | Telegram ID администратора (числом).                        |
| `ENCRYPTION_KEY`    |     ✅      | —               | Ключ шифрования токенов в БД. См. ниже, как сгенерировать.   |
| `DB_PATH`           |     ❌      | `/data/bot.db`  | Путь к файлу SQLite с данными пользователей и аккаунтов.     |
| `CHECK_INTERVAL`    |     ❌      | `300` (сек)     | Как часто фоновый монитор опрашивает лимиты. Минимум `60`.   |
| `INVITE_TTL`        |     ❌      | `86400` (сек)   | Срок жизни одноразовой инвайт-ссылки.                        |

### Генерация `ENCRYPTION_KEY`

```bash
python -m app.crypto
```

Команда выведет случайный ключ Fernet. Сохраните его в переменной окружения
`ENCRYPTION_KEY` и **больше не меняйте**.

> ⚠️ **Потеря `ENCRYPTION_KEY` = потеря доступа ко всем сохранённым токенам.**
> Расшифровать их без ключа невозможно — всем пользователям придётся заново
> подключать свои аккаунты Claude.

## 🛠️ Развёртывание в Coolify

1. Перейдите в **Coolify** → **Applications** → **+ Add Resource** → **Public/Private
   Repository** и укажите этот репозиторий (тип сборки — **Dockerfile**, `Dockerfile`
   уже есть в корне).
2. Во вкладке **Environment Variables** добавьте `BOT_TOKEN`, `ADMIN_TELEGRAM_ID`,
   `ENCRYPTION_KEY` (см. выше), при желании — `CHECK_INTERVAL` и `INVITE_TTL`.
3. Во вкладке **Storages** примонтируйте persistent volume на `/data` — там лежит
   `bot.db` со всеми пользователями, аккаунтами и зашифрованными токенами. Без
   persistent storage база данных потеряется при каждом пересоздании контейнера.
4. Нажмите **Deploy**.

Для локального запуска в Docker вместо ручного `docker build`/`docker run` есть
`docker-compose.yml` — значения переменных подхватываются из `.env` в корне проекта
или из окружения shell.

## 🚀 Первый запуск

1. После деплоя откройте чат с ботом в Telegram и отправьте `/start` **с аккаунта,
   чей Telegram ID указан в `ADMIN_TELEGRAM_ID`** — только этот пользователь
   становится администратором автоматически, всем остальным нужен инвайт.
2. В открывшемся меню нажмите «Добавить аккаунт», чтобы подключить свой первый
   аккаунт Claude (см. ниже).

---

## 🎟 Как пригласить пользователя

В меню администратора выберите **«Управление доступом» → «Создать инвайт»** — бот
пришлёт одноразовую ссылку вида `https://t.me/<bot>?start=inv_<token>`, действующую
`INVITE_TTL` секунд (по умолчанию сутки). Пользователь переходит по ссылке, жмёт
`/start` — и получает доступ к боту.

---

## ➕ Как добавить аккаунт Claude

1. В меню бота нажмите **«Добавить аккаунт»** (или «Перелогиниться», если аккаунт
   уже подключён, но токен истёк).
2. Нажмите кнопку **«Войти в Claude»** — откроется страница авторизации Anthropic.
3. Войдите нужным аккаунтом Claude и на странице с кодом нажмите **Copy Code**.
4. Вернитесь в Telegram и вставьте скопированный код в чат с ботом — сообщение с
   кодом автоматически удаляется сразу после обработки.

> Прямой редирект обратно в Telegram технически невозможен: Anthropic принимает
> только заранее зарегистрированные `redirect_uri` и отклоняет посторонние адреса,
> поэтому код нужно скопировать вручную через **Copy Code**.

## 💻 Локальная разработка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements-dev.txt

export BOT_TOKEN=...
export ADMIN_TELEGRAM_ID=...
export ENCRYPTION_KEY=$(python -m app.crypto)

python -m app.main
```

Запуск тестов:

```bash
pytest
```
